Privacy policy

Last updated November 10, 2026

This page describes what information is involved when you visit Check Desk. The site is operated by Richard Casey. It is a static informational website and has no user accounts.

What this draft site does not collect

The pages are static files. There are no accounts, comment forms, or checkout flows. No analytics token is configured in the site builder, so the published HTML does not include an analytics script.

Hosting logs (when the site is deployed)

When the site is later served from a host (the planned setup is Amazon S3 and CloudFront, like Errand Desk), that host may keep standard request logs. A log entry can include the page or file requested, the date and time, and technical details such as an IP address and browser type. We do not use those logs to identify you, and this site does not use them to show you ads.
