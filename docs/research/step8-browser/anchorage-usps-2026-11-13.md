# Anchorage, AK: USPS locator research (2026-11-13, America/Denver)

Research only. Nothing was built, committed, or deployed. No business was contacted. No browser was used. last_verified: 2026-11-13. Official detail pages that were fetched are marked verification_status `verified_official_locator`. Hours below are **Alaska Time**. City-limits wording: Anchorage is a **consolidated city-borough** (Census "Anchorage municipality" GEOID 0203000). The county-equivalent on every in-municipality row below is Anchorage Municipality (GEOID 02020). The Census place name is "Anchorage municipality," not "Anchorage city"; a USPS printed city of Anchorage is treated as agreeing with that place.

## Method

- **Locator:** official USPS Location Finder API (`https://tools.usps.com/UspsToolsRestServices/rest/POLocator/findLocations`, `requestType` po), queried with curl the same way as the Alabama and Colorado cities. Pass 1 (`sweep.py`): 5 and 15 miles around every Anchorage ZIP (the 28 USPS-city Anchorage codes listed for Anchorage, AK by ZIP-Codes.com from USPS data last updated 2026-11-01: 99501-99511, 99513-99524, 99529, 99530, 99540, 99599, and 99695). 99505/99506 are also listed for JBER / Fort Richardson / Elmendorf AFB (aliases on the Anchorage page). 99540 is also listed for Indian / Bird Creek (aliases Anchorage, Bird Creek). Nearby official ZIPs: 99577 (Eagle River), 99567 (Chugiak), 99587 (Girdwood), 99693 (Whittier; Girdwood is an alias), 99605 (Hope), 99623/99629/99652/99654/99687 (Wasilla / Big Lake / Houston / Meadow Lake), 99645 (Palmer), 99674 (Sutton / Chickaloon), 99688 (Willow), 99683 (Trapper Creek; Willow is an alias on that page), 99676 (Talkeetna), 99572 (Cooper Landing), 99631 (Moose Pass), 99664 (Seward). 92 queries, all JSON, **28 unique Post Office records**. ZIP 99693 (Whittier) returned 0 locations at both 5 and 15 miles (not a parse failure). Pass 2 (`sweep2.py`): 1, 2, 3, 10, and 20 miles around 20 Anchorage/edge and nearby official ZIPs (99501-99504, 99507, 99508, 99515, 99517, 99530, 99540, 99577, 99567, 99587, 99693, 99605, 99654, 99645, 99664, 99688, 99623); added 0 records. 99693 was still 0 at 1-20 miles; a one-off 30-mile query around 99693 returned only the already-known Girdwood office. Total **28 records** (`usps_all.json`, `usps_summ.txt`). Note: when nothing lies inside a very small radius the API returns a default ~26-30 nearest list, so some 1-2 mile queries show large counts; that only widens coverage. 99540 (Indian / Bird Creek) at 15 miles returned fewer records than at 5 miles; the 20-mile pass-2 query around 99540 returned the same known set and added nothing new.
- **Official pages:** `https://tools.usps.com/locations/details/<id>` fetched with curl about 2:15 PM MT for all 28 records. All returned **HTTP 200 on the first try** (`http.txt`, `d<id>.html`). Each page embeds the official `poDetail` record; `pages.py` parsed it and confirmed name, address, phone, and BUSINESS hours match the API record for all 28 (`pages.json`). "Retail hours" = the `BUSINESS` block only (not lobby, PO Box, pickup, holiday, bulk-mail, or APC).
- **City limits:** all 28 addresses through the Census Geocoder address endpoint and all 28 official locator map points, each against both Public_AR_Current / Current_Current and Public_AR_Census2020 / Census2020_Census2020, Incorporated Places + CDPs + Counties (`usps_geo_all.jsonl`). Joined view: `joined.txt`. Structured output: `/workspace/step8anc/anchorage_usps_records.csv` / `.json` (28 rows, `build.py`). OpenStreetMap was not used.
